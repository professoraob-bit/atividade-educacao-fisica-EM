# Atividade Assíncrona de Educação Física — Firebase

Arquivos:
- index.html — página do aluno
- professor.html — painel do professor
- student.js — sorteio, aplicação e registro da tentativa
- professor.js — login, resultados, filtros, detalhes e CSV
- styles.css — layout responsivo

## Antes de publicar
1. Teste localmente.
2. O arquivo serviceAccountKey.json NÃO faz parte deste site e não deve ser colocado nele.
3. A correção é calculada automaticamente no painel do professor usando as respostas salvas e os gabaritos privados do Firestore.
4. O aluno recebe apenas a mensagem de conclusão, sem nota.

## URLs
Aluno: index.html
Professor: professor.html

Observação: o projeto usa Firebase Web SDK por CDN. O firebaseConfig no código do site contém somente a configuração pública do app web.
